# Mayble

A simple desktop book management application.

![Mable Screen Shot](./images/Screenshot.png)

## Motivation

I was asked by a family member of mine, whom has a collection of physical books and needed a way to keep track of them without using using pen and paper, and so I create this CRUD application for them. The application's aim is to keep track of what book has been read, and what has been loaned out, and to whom.

## Quick Start

There are pre-build packages in the [release page](https://github.com/dubbersthehoser/mayble/releases/latest).

*note:* For the **Linux** package, once extracted you can run the binary directly form the `./usr/share/bin/`

### But my platform is not in the releases?

Then build from source.

1. Clone down repo: `git clone github.com/dubbersthehoser/mayble`

2. Install the Go language (v1.24.0 or higher)

2. Install Fyne command line tool `go install fyne.io/tools/cmd/fyne@latest`.

3. Build and run `fyne build .` then `./mayble` try it out.
